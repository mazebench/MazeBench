# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through the repository's
**Security** tab by choosing **Report a vulnerability**. Do not open a public
issue for an undisclosed security problem.

Include the affected component or version, reproduction steps, impact, and any
suggested remediation. Please avoid accessing data that is not yours,
disrupting hosted services, or publishing details before a fix is available.

The maintainers will acknowledge a report as soon as practical, investigate
it, and coordinate disclosure and remediation with the reporter.

## Supported versions

Security fixes are applied to the current `main` branch and then released in
the next MazeBench PyPI and/or Prime Environment Hub version as appropriate.
Older releases may require an upgrade rather than a backport.
